s1d1-alliance

s1d1 is a small multilingual model that reads a prompt once and returns a complexity score, one task among 19 and a needs-tools flag, so an LLM router can send each request to the right model. This is a free community instance of it.

Try without sending anything

The private demo runs the model in your browser: nothing leaves your machine.

You can also self-host the same model with s1d1-tantive, or read the model card.

Use and contribute

This instance is free, and what you send improves s1d1. Tick the box to see the API URL and the tutorial.

API

Base URL: https://s1d1.qoo.gy/api/v1. Limit: 100 requests per 10 s per IP; on a 429, retry later or fall back to your default model.

Tutorial

LiteLLM

Register s1d1 as the classifier of the Auto Router, using the chat-completions or the decisions format, with the base URL https://s1d1.qoo.gy/api/v1. Map the tiers it returns to your own models. Details: docs/litellm.md in s1d1-tantive.

curl

curl -s https://s1d1.qoo.gy/api/v1/systemone \
  -H 'content-type: application/json' -d '{
  "state": "Write a Terraform module",
  "questions": {"tier": {"type": "choice",
    "criteria": {"TRIVIAL": "", "LOW": "", "MEDIUM": "", "HIGH": "", "EXPERT": ""}}}}'

n8n

Use an HTTP Request node that POSTs the same JSON to that URL, then branch on the returned tier.

Contribute


Requests to this instance are kept, anonymised and used to retrain the model. To send your own self-hosted captures, follow the capture guide; the wire format is in contract/ingest-v1.md. The infrastructure is public in s1d1-alliance.
