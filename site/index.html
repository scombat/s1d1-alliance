Send each prompt
to the right model.

s1d1 reads a prompt once and tells your router how hard it is, what kind of task it is and whether it needs tools, so easy prompts go to cheap models and hard ones to strong models.

Freehosted API, no account, no key
~20 msper decision, before the LLM call
19 tasksmultilingual, open weights (Apache-2.0)

Two ways to use it

Same model, same API. Only where it runs changes.

Use the free API, and contribute

  • Nothing to install: point your router at one URL.
  • What you send is kept, anonymised and used to retrain s1d1.

Run it yourself, privately

  • One container, CPU only, ~20 ms.

Set it up in two minutes

Pick what you use. Each snippet is complete: copy, paste, run. Self-hosting? Replace https://s1d1.qoo.gy/api with your own URL.

1 · config.yaml (LiteLLM 1.106 or later)
model_list:
  # … your four models: cheap, medium, strong, reasoning
  - model_name: s1d1-auto
    litellm_params:
      model: auto_router/complexity_router
      complexity_router_default_model: medium
      complexity_router_config:
        classifier_type: oss_classifier
        opensource_classifier_config:
          provider: laya
          model: multilingual
          api_base: https://s1d1.qoo.gy/api
          timeout_ms: 1000
        classifier_fallback: default_model
        tiers:
          SIMPLE: cheap
          MEDIUM: medium
          COMPLEX: strong
          REASONING: reasoning
2 · Call it like any model
"model": "s1d1-auto"

An HTTP Request node, then a Switch node on the tier
POST https://s1d1.qoo.gy/api/v1/systemone
Body (JSON): {"state": "{{ $json.prompt }}",
  "questions": {"tier": {"type": "choice", "criteria":
  {"SIMPLE": "", "MEDIUM": "", "COMPLEX": "", "REASONING": ""}}}}
# Switch on {{ $json.answers.tier.choice }}
curl -s https://s1d1.qoo.gy/api/v1/systemone \
  -H 'content-type: application/json' \
  -d '{"state":"Write a Terraform module","questions":{"tier":
  {"type":"choice","criteria":{"SIMPLE":"","MEDIUM":"","COMPLEX":"","REASONING":""}}}}'

Other paths: /v1/systemone/batch, /v1/decisions, /v1/chat/completions, /classify, /predict; GET /v1/models.

import httpx

def classify(prompt: str) -> str:
    r = httpx.post("https://s1d1.qoo.gy/api/v1/systemone", json={
        "state": prompt,
        "questions": {"tier": {"type": "choice", "criteria":
            {"SIMPLE": "", "MEDIUM": "", "COMPLEX": "", "REASONING": ""}}}},
        timeout=1.0)
    return r.json()["answers"]["tier"]["choice"]
OpenRouter, Portkey, your own proxy: ask s1d1 first, then pick the model
from openai import OpenAI

MODELS = {"SIMPLE": "cheap", "MEDIUM": "medium",
          "COMPLEX": "strong", "REASONING": "reasoning"}
tier = classify(prompt)  # the function of the Python tab
client = OpenAI(base_url="https://openrouter.ai/api/v1", api_key=KEY)
client.chat.completions.create(model=MODELS[tier], messages=[...])

Any gateway that takes a model name works this way.

Limit: 100 requests per 10 s per IP. On a 429 or a 503, fall back to your default model.
